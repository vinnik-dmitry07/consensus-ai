# Finish probe v2: the rest of v1

Written before the first paid call of `finish-probe-v2`. Everything in [finish-probe-protocol.md](finish-probe-protocol.md) stands unless this file changes it. The commit that holds this file also holds the code; the labels are committed before the first measurement call.

## Why v1 stopped

The pilot and the main run of `finish-probe-v1` wrote to one budget journal. Five pilot texts from test (15 cells) are also main cells and got the same attempt ids. The first of them was refused as already settled and the runner stopped at 112 of 363 main cells: $1.8342 settled, $0.1357 held for two POSTs with no outcome, 151 POSTs. The v1 labels were written by Anthropic models, which the owner of the experiment does not allow for extracting or analysing results.

## What v2 changes

1. **v1 is closed.** Its code, labels, and journals are not changed. Its 112 finished main cells are read as they are from `.runs/finish-probe-v1/main/events.jsonl`. That file, the v1 budget journal, and the v1 pilot settings are hashed at the v2 freeze, and v2 refuses to run or report if they change.
2. **The other 251 main cells are sent in v2.** Same sources, prompts, routes, reasoning efforts, caps from the v1 pilot (2048 on all three routes), order seed, concurrency, and retry rules. They go to their own run folder and budget journal, so no pilot attempt id can collide with them.
3. **The two v1 cells whose POST was cut by the crash are sent once in v2.** Their answers were never received. This is a decision made here, not an automatic repeat; inside v2 a POST without an outcome is still never sent again. Their v1 reserve stays counted as spent. The cell that crashed v1 made no POST and is simply pending.
4. **Limits stay those of the approved experiment, across v1 and v2:** v2 may spend $10 minus v1's settled and held money, and 500 minus v1's POSTs.
5. **New labels from two OpenRouter models.** The v1 labels are not used. Pass A is `openai/gpt-6.1-sol`, pass B is `google/gemini-4-argon`, both at reasoning effort `low`. Neither is from Anthropic or on the council. Each pass gets the same 51 texts, the same gold-free excerpts, and the instructions of the v1 passes, one text per call. A model may ask once for the full text. A reply that is not a valid label is asked again, at most twice. Groups and agreed values come from the same code as in v1. Labelling is capped at $5 on its own, outside the experiment limit, because the v1 plan had labelling without the paid key.
6. **A call that ended in an error after its allowed attempts is "no answer"**, as the protocol text says. The v1 code counted such a call as incomplete; v1 had none.
7. **Relaunches.** A cell refused for capacity is asked again after the cooldown by the next launch, up to 40 launches. A cell still pending after that is incomplete, and the criteria it touches stay undetermined.

The criteria, thresholds, policies, decision rule, sensitivity set, and leave-one-question-out are unchanged. The report counts v1 and v2 together and shows where each cell came from.

## Who does what

Code computes every number, group, and decision. No Anthropic model labels, extracts, grades, or corrects a result. The README note is generated by the report code from `report.json`.

## Limits of the reading

All of v1's limits apply. In addition, the person running v2 had seen v1's interim numbers on 112 cells before writing these rules and choosing the label models. The labellers see no gold, no arm, and no extra answer.
